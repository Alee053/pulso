# Pulso Context

Pulso helps people discover and evaluate projects in the entrepreneurial ecosystem. This glossary records the product terms already visible in the prototype; terms remain provisional until product requirements are finalized.

## Discovery

**Project**:
An entrepreneurial initiative represented in Pulso, including its public profile, team, stage, and opportunities.
_Avoid_: startup when referring to the canonical domain concept, opportunity for the whole project, company card

**Startup**:
A familiar discovery label that can describe a project, but is not the canonical domain term for every entrepreneurial initiative.
_Avoid_: using startup as the general name for all Pulso projects

**Founder**:
A person identified as part of a project's founding team.
_Avoid_: using owner for the public founding-team person; user

**Interest**:
A signal selected by a person to describe what they want to discover or support.
_Avoid_: filter, tag, preference

**Discovery feed**:
An ordered set of project profiles presented for evaluation.
_Avoid_: list, search results

**Recommendation**:
The explanation or signal that describes why a project is relevant to the selected interests.
_Avoid_: score, ranking

## Person actions

**Saved project**:
A project a person keeps for later review without necessarily expressing active interest.
_Avoid_: favorite, bookmark

**Interested project**:
A project for which a person has explicitly expressed interest.
_Avoid_: liked startup, match

## Projects

**Publication request**:
The team action that moves a draft project into administrative review without making it publicly discoverable.
_Avoid_: publish, go live, submit as a synonym for becoming public

**Administrative review**:
The platform decision that approves or rejects a project for public discovery.
_Avoid_: team publish, owner publish

**Archived project**:
A project the team has withdrawn; it is no longer publicly discoverable and is not reopened by requesting publication.
_Avoid_: deleted project, unpublished draft, hidden project

**Project owner**:
The active membership role with full control of a project's team actions, including publication request and archive.
_Avoid_: founder when referring to the membership role, user

**Project admin**:
The active membership role that can administer a project and perform the same publication-request and archive actions as a project owner.
_Avoid_: moderator, platform admin

## Team

**Member invitation**:
A project team row that offers a person a place on the project before they belong to it, identified by the project and invitee email until acceptance.
_Avoid_: invitation as a separate entity, pending member, invite record

**Invitee email**:
The normalized email that identifies the invited person while the membership still has no profile.
_Avoid_: user email, username, account email

**Active invitation**:
A member invitation whose membership status is INVITED. A second active invitation for the same project and normalized invitee email is a duplicate.
_Avoid_: open invite, pending invite as a second status
